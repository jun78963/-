失智症不是正常老化！

核心鑑別：正常老化 vs 失智症 vs 譫妄 vs 憂鬱

狀態 起病模式 意識與注意力 典型特徵 第一線處置方向
正常老化 緩慢 清楚正常 偶爾忘事，經提醒通常能想起；生活獨立 健康促進與大腦保養
失智症 (Dementia) 慢性漸進退化 多半清楚 近期記憶差、重複問、失去判斷、IADL/ADL 下降 神經內科評估、長照資源整合
譫妄 (Delirium) 急性發作、日夜波動 混濁、注意力明顯缺損 突發幻覺、躁動狂躁或嗜睡、日夜顛倒 醫療急症！急查感染/電解質/藥物
憂鬱 (假性失智) 可急可緩 清楚 無精打采、自覺記憶很差、回答常說「不知道」 心理支持、抗憂鬱評估
最常見類型 (約50-60%)

阿茲海默症 (AD)

以近期記憶退化、定向力障礙為最早警訊；海馬迴萎縮，蛋白質異常沉積。

照護核心：外部提示、固定作息、避免頻繁指責與正面考驗。
第二常見 (約20-30%)

血管性失智症 (VaD)

常有中風或心血管病史，症狀常呈「階梯式惡化」，早期執行力與步態不穩常見。

照護核心：控制三高（血壓血糖血脂）、防範再次中風與復健防跌。
特徵鮮明

路易氏體失智症 (DLB)

鮮明生動的「視幻覺」（如看到小孩動物）、認知狀態忽好忽壞、伴隨巴金森小碎步。

照護核心：對抗精神病藥高度過敏需謹慎，以陪伴降低恐懼。
常早發於65歲前

額顳葉失智症 (FTD)

早期記憶力尚可，但個性急劇改變、出現脫序失禮言行、衝動亂花錢或漸進性語言障礙。

照護核心：環境安全界線管理、財務法律防護與照顧者心理支持。

照護常見 NG 互動

  • 直接反駁與爭辯：「剛剛才說過，你怎麼又忘了！」會加深個案挫折與焦慮。
  • 嚴格考核與測驗：「你猜我是誰？今天是民國幾年？」容易引發挫折感與敵意。
  • 半夜大聲命令：當長者夜間想出門，大聲斥喝「不准出去」常誘發激躁或攻擊。

正向照護溝通四步曲

  • 先安全：瓦斯爐火、夜間玄關照明防跌與走失防護優先。
  • 先同理：「我知道你掛念老家，我們先坐下喝杯溫開水慢慢說。」
  • 找需求：BPSD 不是故意找麻煩，常反映飢餓、疼痛、想上廁所或環境太吵。
  • 再轉移：以日常照片、熟悉懷舊話題或輕柔音樂引導個案注意力。

2. 點選「擴充功能」→「Apps Script」，貼入以下程式碼並部署為「網頁應用程式 (任何人皆可存取)」：

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["提交時間", "姓名", "科系", "學號", "總分", "答對題數", "作答明細"]);
  }
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    new Date(),
    data.name,
    data.department,
    data.studentId,
    data.score,
    data.correctCount,
    JSON.stringify(data.answers)
  ]);
  return ContentService.createTextOutput(JSON.stringify({result: "success"})).setMimeType(ContentService.MimeType.JSON);
}
